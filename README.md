
# GitHub Security Testing Lab

This project is designed to practise GitHub security features.

## Security Features

1. Dependabot Alerts
2. Secret Scanning
3. CodeQL Code Scanning

## Intentionally Included Examples

- Outdated Python dependencies
- Fake hardcoded token
- SQL Injection example
- Command Injection example
- Weak MD5 hashing

WARNING:
This application contains intentionally vulnerable code.
Do not deploy it to production or expose it to the internet.
